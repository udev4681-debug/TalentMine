Architecture Summary

TalentMine is structured as a decoupled application: a high-performance Modular Frontend (HTML5, Vanilla CSS, and JavaScript) paired with a PHP REST API Backend with JSON data stores for candidate mining, validation, and dataset exports.

1. System Prerequisites

To run the platform locally, ensure you have the following installed on your machine:

1. PHP (Version 8.0 or Higher)

Required to serve the backend REST endpoints and execute local web servers. Verify in terminal via: php -v.

2. Modern Web Browser

Google Chrome, Microsoft Edge, Firefox, or Brave with JavaScript and Canvas support enabled.

2. Method 1: Using the Built-in PHP Server (Recommended & Fastest)

PHP comes with a built-in development web server that does not require installing or configuring heavy third-party software.

1
Open Terminal / PowerShell in Project Directory

Navigate to the project directory where the codebase is located:

cd C:\Users\ibrah\code\etc\TalentMine
2
Start the PHP Development Server

Run the following command to bind the web server to port 8000:

php -S 127.0.0.1:8000

Note: Keep this terminal window open while using the application. To stop the server at any time, press Ctrl + C.

3
Navigate to the Application in Chrome

Open Google Chrome and enter the following URL in the address bar:

http://127.0.0.1:8000

The root URL automatically routes to the modular workspace at http://127.0.0.1:8000/frontend/index.html, connecting automatically to the live PHP API backend.

3. Method 2: Running with XAMPP (Apache + PHP)

If you prefer a full graphical stack with Apache, you can run TalentMine through XAMPP.

1
Install and Open XAMPP

Download and install XAMPP from apachefriends.org if not already installed. Launch the XAMPP Control Panel.

2
Place Project in the htdocs Directory

Copy or move the entire project folder into your XAMPP web root directory:

C:\xampp\htdocs\TalentMine
3
Start the Apache Service

In the XAMPP Control Panel, find the Apache module and click the Start button. The status will turn green indicating it is running on ports 80 and 443.

4
Navigate in Your Web Browser

Open Google Chrome and visit:

http://localhost/TalentMine

Or navigate directly to http://localhost/TalentMine/frontend/index.html.

5. Troubleshooting Common Issues

Port 8000 is already in use

If port 8000 is occupied by another process, start on another port like 8080: php -S 127.0.0.1:8080, then visit http://127.0.0.1:8080.

'php' is not recognized as an internal or external command

Add the path to your PHP executable (e.g., C:\xampp\php or C:\php) to your Windows Environment Variables under System PATH.
