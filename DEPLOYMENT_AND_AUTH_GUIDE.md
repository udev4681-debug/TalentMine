# Running the Server

### Option 1: Using Built-in PHP Server (Fastest)

1. Open your terminal in the project directory:
   ```powershell
   php -S 127.0.0.1:8000
   ```
2. Open Google Chrome (or any browser) and navigate to:
   ```
   http://127.0.0.1:8000
   ```

---

### Option 2: Using XAMPP

1. Install and open **XAMPP Control Panel**.
2. Start the **Apache** module (click **Start**).
3. Place this project folder inside your XAMPP web directory:
   ```
   C:\xampp\htdocs\TalentMine
   ```
4. Open Google Chrome and navigate to:
   ```
   http://localhost/TalentMine
   ```
   *(or `http://localhost/TalentMine/frontend`)*
